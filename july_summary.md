# July 2026 — Month 2 Summary

## 5 Things I Can Now Do That I Could Not Before

1. Design and build a PostgreSQL database schema from scratch
   including tables, foreign keys, constraints and relationships

2. Build a complete REST API with FastAPI — routes, validation,
   error handling, async routes, pagination and tests

3. Connect Python to PostgreSQL using psycopg2 — insert, query,
   update and delete data with parameterized queries

4. Write pytest test suites with fixtures, cleanup and
   assertions that cover happy paths and error cases

5. Think in systems — design a route by picturing the full flow
   from request to database to response before writing any code

## 2 Things Still Unclear

1. Async internals — I understand when to use async and await
   but the underlying event loop mechanics are still fuzzy

2. Complex CTE chains — single CTEs are clear but chaining
   multiple CTEs together on complex data still requires thinking

## 1 Thing That Surprised Me

How quickly the fear disappeared. Six weeks ago I was scared
of anything coding related. Now I build FastAPI routes from
memory and catch mistakes in my own code before running it.
Once I started building real things the unknown became familiar.
